Disney Solitaire

A month later I joined Disney Solitaire as a Unity Technical Artist and that's where the magic began.

Adobe Creative Suite

In spring 2026 I took an Adobe Creative Suite course led by Artemisa Pascu and Andrei Grosu of Local Design Circle, going from beginner to junior level in Photoshop, Illustrator and InDesign.

My day to day is spent inside Unity, so I wanted to go back to the 2D fundamentals behind every asset I integrate: vector construction, photo editing and colour grading, typography and editorial layout.

Each homework came with a brief. Here are the projects I made:

Vector Icon Set

Project 01
Illustrator
Vector Icon SetPen Tool · Shape Builder · flat colour
Inspector
Vector Icon Set
Style Guide
Before drawing anything, I set a few rules for the whole set: bold outlines, flat fills, rounded corners and a shared palette, so the five icons read as one family.
Construction
Each icon started from simple primitives combined with the Shape Builder and Pathfinder, then refined with the Pen Tool into clean, scalable paths.
Readability
Coming from game UI, I designed each icon silhouette first, so it still reads at small sizes, exactly what an icon needs in a HUD or a shop screen.

Vector Illustration

Project 02
Illustrator
Vector IllustrationPen Tool · Blend Tool · gradients
Inspector
Vector Illustration
Composition
A retro psychedelic illustration of a cat figure holding two meteorites. I built it on a mirrored, symmetrical composition and broke the symmetry in the middle with the third eye and the sharp shapes behind it, so the focal point stays in the center.
Pen Tool
Every shape, from the fluid background waves to the hands, was drawn as a vector path with the Pen Tool.
Blend Tool
I used the Blend Tool to generate the stepped rings inside the eye and the ridges on the meteorite handles, adding depth while staying 100% vector.
Gradients
I combined linear, radial and freeform (points) gradients for a smooth and harmonious colour blend across the whole piece.
Project
+All

Blend Tool stepped shapes
Linear, radial and freeform gradients

Album Artworks

Project 03
Photoshop
Album ArtworksPhoto compositing · Levels · colour grading
Inspector
Album Artworks
Concept
Two album artworks, each one combining several photos into a single composition. The first one started from a retro, melancholic vaporwave mood, the second one from something much more aggressive.
Colour Grading
On the vaporwave piece I pushed Levels on my cat to get the neon colours, then again on the phone booth to give its interior an unnatural, cyberpunk glow. For the mantis I used Levels, Hue/Saturation and contrast for an aggressive colour look.
Compositing
Old cellphones under a pastel overlay became the background, keeping the colour theme while making the subjects pop, and a few odd figures behind the phone booth add an accent. For the mantis, I smudged a church and turned it into the mantis' fire spit, with barbed wire brushes enhancing the metal look.
Typography
Japanese type in pastel colours enhances the retro vibe. The “Death Mantis” title was built from vector art and multiple fonts, the Japanese lettering is filled with orchids through clipping masks, and a “Smerenie” label in the background provides depth.
Project
+All
Album Artworks
Brief
Photo editing (portraits and/or products) + colour grading + composition.
Techniques
Levels and Hue/Saturation adjustments
Layer masks and clipping masks
Blend modes and colour overlays
Smudge Tool and custom brushes
Type integrated into the composition

Inspector
Poster Series
Concept
A series of three posters for an Adobe Creative Suite workshop: learn to use InDesign, Illustrator and Photoshop properly and build a functional workflow for any design direction, from beginner to junior.

All three posters share the same building blocks: a pixel-style header, dashed-outline text boxes, the instructors' credits and a vertical date. about_me.txtEva Bulai

I had the opportunity to work hand in hand with QA, Dev, Art, Animations, Product, Monetization departments which at first was overwhelming but as time went by it felt like second nature. Besides other attributes as a Technical Artist, the main objective was to be a bridge between the technical side and the artistic side, while also understanding Product and Monetization needs.

At first I was assigned to a team consisting in 1 Technical Artist, 2 QA, 1 Dev and 1 Product; but as I further improved my skills I got the amazing opportunity to work hand in hand with all the teams on the project and be part of multiple other features, which proved to be a great experience in terms of team work, people management and Tech Art expertise.

Working with an Agile timeline, with short tight deadlines, I quickly learned how to manage my time efficiently, take the best technical decisions so the deliverables would be to the highest standard possible, work smoothly and look as whimsical and amazing as possible.

Overall, besides the technical skills, this project taught me how to understand all job families, and how to create a synergy between departments to get the best outcome possible for each feature developed.
